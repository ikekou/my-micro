# Codex Micro keycap artwork

These SVG files reproduce the keycap artwork bundled in the locally installed OpenAI desktop application (Codex Micro keyboard surface and associated icon modules). Original path data, view boxes, fills, and strokes are preserved. The SVG files are displayed in a fixed 20 × 20 CSS pixel box, including the wide microphone key.

Artwork is attributed to OpenAI and is not covered by My Micro's MIT code license. No separate redistribution license is asserted here. My Micro is an unofficial community project and does not claim OpenAI endorsement. These files are distinct from the MIT-licensed apps-sdk-ui icon collection.

Internal IDs SPLIT and BRCH appear as FORK and DRAFT in the original picker. MIND-plus.svg and MIND-minus.svg correspond to MIND+ and MIND-. YOLO/YEET are rendered as text; empty keycaps contain no artwork.
